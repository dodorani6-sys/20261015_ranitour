# 라니투어 (Rani Tour) 🚗 🗺️

카카오 지도(Kakao Maps API) 기반 반응형 여행 일정 플래너 웹 애플리케이션입니다.

## 주요 기능
- **2-Column 반응형 레이아웃**: 데스크톱 분할 뷰 & 모바일 전용 토글
- **카카오 지도 & 동선 연동**: 일차별 커스텀 넘버링 마커(1, 2, 3...) 및 경로(Polyline) 시각화
- **실시간 장소 검색**: 카카오 로컬 키워드 검색 서비스 연동
- **거리 및 소요시간 계산**: 장소 간 거리와 이동수단(`차로` / `도보`) 원클릭 전환 및 일차별 총 소요시간 자동 합산
- **내 여행 보관함**: 여러 여행 일정(속초, 제주 등) 생성, 보관, 복제 및 실시간 전환
- **공유 모드**: URL 데이터 스마트 압축 공유 지원 (가족/친구용 읽기 전용 뷰어)

## 시작하기

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

## 환경 변수 설정 (.env.local)

```env
NEXT_PUBLIC_KAKAO_MAP_API_KEY=발급받은_JavaScript_키
```
